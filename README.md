🌟 NGO Awareness Webpage – InAmigos Foundation

📌 Project Overview

This project is a modern and responsive NGO Awareness Webpage developed using HTML and CSS. The website aims to spread awareness about the initiatives and social impact of InAmigos Foundation by presenting information in a clean, user-friendly, and visually appealing manner.

🎯 Objective

The purpose of this project is to create awareness about the NGO's mission, ongoing projects, and social contributions while encouraging people to participate as volunteers and supporters.

✨ Features

* Responsive and modern user interface
* Introduction to InAmigos Foundation
* Information about ongoing projects and initiatives
* Social impact and purpose of the organization
* Attractive cards and sections with hover effects
* Call-to-action section for volunteering and support
* Smooth navigation and clean layout
* Personalized footer with developer details

🛠️ Technologies Used

* HTML5
* CSS3

🌍 Impact

This webpage highlights the efforts of InAmigos Foundation in areas such as education, women empowerment, environmental sustainability, community welfare, and animal care. It aims to inspire individuals to contribute towards building a better society.
